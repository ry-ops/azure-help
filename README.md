# azure-help

Personal notes and playbooks for working with the Azure portal — things that turned out to be
non-obvious, painful, or worth not re-discovering from scratch next time.

## Contents

- [`refund-request-process.md`](./refund-request-process.md) — how to request a refund/credit for
  an Azure billing charge, including how to work around the self-service refund tool's hidden
  "expedited refund" limit and a broken link in the support-ticket wizard's self-help overlay.

## Why this exists

Azure's billing and support UI has a few flows that are inconsistent or flaky enough that it's
worth writing down the exact working steps rather than relearning them each time. These docs are
written from direct experience filing real refund requests, including the dead ends that didn't
work.
